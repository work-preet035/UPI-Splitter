# Security Policy

## Reporting a vulnerability

Please do not publish sensitive security issues, credentials, payment information, or exploitable details in a public issue.

Contact the repository owner privately through the contact method listed on the owner's GitHub profile and include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Relevant proof of concept with secrets removed

## Payment safety

This project generates UPI payment instructions; it does not process or authorize payments.

Always verify the recipient UPI ID, recipient name, and amount in the UPI application before confirming a transaction. Never share a UPI PIN, OTP, banking password, or authentication secret with this application.
