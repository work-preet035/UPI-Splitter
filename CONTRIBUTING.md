# Contributing

Thanks for contributing to UPI QR Payment Splitter.

## Development

1. Use Python 3.10 or newer.
2. Create a virtual environment.
3. Install dependencies with pip install -r requirements.txt.
4. Run the app with python main.py.

## Pull requests

Keep changes focused and explain what changed, why it was needed, and how it was tested.

Please preserve the stateless/privacy-first design unless a change explicitly requires persistence. Never log payment credentials, UPI PINs, OTPs, or unnecessary personal information.

For security vulnerabilities, follow SECURITY.md rather than opening a public issue.
